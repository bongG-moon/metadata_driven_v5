    메타데이터 연결 상태
    
              
    
              
    MongoDB 상태는 Portal 설정 저장소의 실제 읽기 확인 결과입니다. 요청 가능은 각 Flow의 URL·인증·호출 사번 구성이 완료된 뜻이며, 실제 저장 성공 여부는 등록 결과에서 확인합니다. 메타데이터 목록은 별도의 읽기 전용 MongoDB 조회 상태로 구분해 표시합니다.

    GAIA API 호출 권한 사번
