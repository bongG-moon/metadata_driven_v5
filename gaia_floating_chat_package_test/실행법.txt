1. AI Market 담당자에게 gaia-floating-chat 패키지 설치 방법(사내 npm 레지스트리, tarball 또는 소스)을 받습니다.

2. PowerShell에서 아래를 실행합니다.

cd C:\Users\qkekt\Desktop\metadata_driven_v5\gaia_floating_chat_package_test
Copy-Item .env.example .env
notepad .env

3. .env에 아래 값을 입력합니다.

GAIA_EXTERNAL_GATEWAY_ORIGIN=http://gaia.api.skhynix.com
GAIA_EXTERNAL_GATEWAY_VERIFY_SSL=true
VITE_GAIA_AGENT_URL=/v2/agents/031011/external
VITE_GAIA_API_KEY=AI Market External 인증키
VITE_GAIA_USER_ID=권한 있는 사번 7자리
VITE_GAIA_SESSION_ID=test_사번

4. 담당자 안내에 따라 패키지 설치를 완료한 뒤 실행합니다.

npm install
npm run dev

5. 브라우저에서 http://127.0.0.1:8004 를 엽니다.

참고: 이 테스트는 VITE_GAIA_API_KEY를 브라우저로 전달하므로 개인 개발 PC에서만 사용합니다.
