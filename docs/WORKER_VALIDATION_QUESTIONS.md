# 작업자 관점 추가 검증 질문

이 문서는 기존 `validation_questions.txt`의 자동 검증 질문과 겹치지 않도록 실제 작업자가 입력할 법한 표현을 추가로 정리한 수동 검증 목록이다.

테스트할 때 상대 일자 결과는 실행일에 따라 달라질 수 있다. 더미 환경에서 결과를 고정해 비교하려면 기준일을 `20260701`로 설정한다.

## 1. 공정 그룹과 별칭

1. 오늘 B/G 공정의 생산량과 현재 재공을 같이 알려줘.
   - 확인: `process_groups:BG`가 선택되고 B/G1, B/G2로 확장되는지 확인한다.

2. 오늘 BG공정에서 생산량이 가장 많은 3개 제품을 알려줘.
   - 확인: 일반 명사인 제품을 DEVICE가 아니라 표준 제품 키로 집계하는지 확인한다.

3. 오늘 D/P공정 생산량을 세부 공정별로 보여줘.
   - 확인: DP 그룹에 등록된 세부 공정 전체를 OPER_NAME별로 집계하는지 확인한다.

4. 오늘 W/B공정에서 생산량이 가장 적은 3개 제품을 알려줘.
   - 확인: W/B1~W/B6으로 확장하고 하위 3개 제품을 계산하는지 확인한다.

5. 어제 WB 공정의 차수별 생산량을 많은 순서로 보여줘.
   - 확인: WB와 W/B가 같은 그룹으로 해석되고 W/B1~W/B6으로 나뉘는지 확인한다.

6. 오늘 비엠 공정에서 작업 중인 제품별 재공을 알려줘.
   - 확인: 비엠을 BM/B/M 공정으로 해석하는지 확인한다.

7. 오늘 DVI공정 생산량을 알려줘.
   - 확인: DVI를 DI/D/I 공정의 별칭으로 해석하는지 확인한다.

8. 6월 30일 FCB/H공정에서 생산 실적이 있었던 제품을 보여줘.
   - 확인: FCB/H를 FCBH 단일 공정으로 해석하고 FCB1·FCB2까지 넓히지 않는지 확인한다.

9. 오늘 P/L 공정의 현재 재공 수량을 알려줘.
   - 확인: P/L 또는 PLH를 OPER_NAME=PLH로 해석하는지 확인한다.

10. 오늘 S/G공정의 생산량을 제품별로 알려줘.
    - 확인: S/G 또는 SG를 단일 OPER_NAME=S/G로 해석하는지 확인한다.

11. 오늘 WBM공정과 W/B공정의 생산량을 공정별로 비교해줘.
    - 확인: WBM은 W/BM 단일 공정, WB는 W/B1~W/B6 그룹으로 서로 분리되는지 확인한다.

12. 오늘 D/C 공정에서 생산량이 가장 많은 세부 공정을 알려줘.
    - 확인: D/C1~D/C4로 확장한 뒤 공정별 순위를 계산하는지 확인한다.

13. 오늘 WET공정과 L/T공정의 생산량을 각각 알려줘.
    - 확인: 두 공정 그룹을 하나의 문자열 조건으로 합치지 않고 각각의 세부 공정으로 확장하는지 확인한다.

14. 오늘 HS 공정에서 현재 재공이 많은 제품 5개만 보여줘.
    - 확인: H/S1, H/S2로 확장하고 제품 키 기준 상위 5개를 계산하는지 확인한다.

## 2. 제품 조건과 수량 분석

15. 오늘 A-578 제품의 DA공정과 WB공정에서 생산량과 재공 수량을 각각 알려줘.
    - 확인: A-578을 MCP_NO prefix로 해석하고 DA와 WB 조건을 각각 확장하는지 확인한다.

16. 오늘 생산량이 가장 많은 5개 제품과 가장 적은 5개 제품을 알려줘.
    - 확인: `제품별`이라는 단어가 없어도 표준 제품 키로 먼저 집계하고 DEVICE는 제외하는지 확인한다.

17. RG 32G DDR4 FBGA 96 DDP 제품의 오늘 BG공정 생산량을 알려줘.
    - 확인: 제품 token helper와 BG 공정 그룹 확장이 함께 적용되는지 확인한다.

18. SP 16G DDR5 2ND X4 FC78 제품의 오늘 FCB공정 재공을 알려줘.
    - 확인: X4는 ORG=4, FC78은 PKG_TYPE1=FCBGA 및 LEAD=78로 해석하는지 확인한다.

19. L-218로 시작하는 제품 중 오늘 DA공정 재공이 많은 순서로 보여줘.
    - 확인: MCP_NO prefix와 공정 그룹, 제품별 집계, 정렬이 함께 적용되는지 확인한다.

20. 어제 Mobile 제품의 생산량과 오늘 현재 재공을 제품별로 비교해줘.
    - 확인: production에는 어제 일자, wip에는 오늘 일자가 서로 독립적으로 들어가는지 확인한다.

21. 오늘 POP 제품의 W/B공정 생산량을 제품별로 알려줘.
    - 확인: POP 제품 도메인 조건과 WB 공정 그룹이 동시에 적용되는지 확인한다.

22. 오늘 WBM공정 제품별 생산량을 보여줘. 제품 정보가 비어 있어도 제외하지 마.
    - 확인: 차원 NULL·공백은 빈칸으로 유지하고 생산량 NULL은 0으로 표시하는지 확인한다.

23. 오늘 A조 D/A공정 생산량을 세부 공정별로 알려줘.
    - 확인: A조가 SHIFT=1로 해석되고 DA가 D/A1~D/A6으로 확장되는지 확인한다.

24. 7월 1일 D/A1에서 W/B6까지 공정별 생산량과 재공을 OPER_SEQ 순서로 보여줘.
    - 확인: 양 끝 공정만 필터링하지 않고 전체 OPER_SEQ 구간을 포함하는지 확인한다.

## 3. 장비 배정과 UPH

25. 현재 DA공정에서 L-218K8H 제품을 작업하는 장비를 알려줘.
    - 확인: LOT 조건이 없으므로 lot_status가 아니라 equipment_assign을 사용하는지 확인한다.

26. 현재 WB공정에 배정된 장비 ID와 장비 모델을 보여줘.
    - 확인: 장비 목록 질문이 equipment_assign으로 조회되는지 확인한다.

27. 현재 D/A1 공정에 배정된 장비와 각 장비 Recipe의 UPH를 알려줘.
    - 확인: equipment_assign과 eqp_uph를 장비 모델·Recipe·공정 기준으로 결합하는지 확인한다.

28. D/A1 공정의 장비 모델, Recipe, 공정, 평균 UPH를 낮은 순서로 보여줘.
    - 확인: 기본 상세 컬럼과 UPH metric이 함께 표시되는지 확인한다.

29. 현재 보유 장비를 모델별로 몇 대씩 가지고 있는지 알려줘.
    - 확인: EQUIP_ID 중복을 제거한 뒤 장비 모델별로 count하는지 확인한다.

30. 현재 DA공정 재공이 가장 많은 제품 10개와 그 제품에 할당된 장비를 같이 보여줘.
    - 확인: WIP 제품 집계 후 metadata의 표준 제품 키를 사용해 equipment_assign과 결합하는지 확인한다.

31. 현재 D/A1 공정의 EQUIP_MODEL과 RECIPE_ID별 UPH 차이를 보여줘.
    - 확인: 설명에만 장비 모델·Recipe를 언급하지 않고 결과 테이블에도 포함하는지 확인한다.

## 4. LOT·HOLD·TAT

32. 현재 HOLD 중인 LOT을 HOLD 사유와 현재 공정 기준으로 보여줘.
    - 확인: LOT 단위 질문이 lot_status를 사용하고 LOT_ID를 기본 식별자로 포함하는지 확인한다.

33. LOT T9999999GEN1의 현재 공정, 장비, HOLD 상태와 누적 TAT를 알려줘.
    - 확인: 명시적인 LOT_ID 조건이 lot_status에 적용되는지 확인한다.

34. DA공정 재공이 가장 많은 제품의 LOT 수, UNIT 수량, Wafer 수량을 알려줘.
    - 확인: WIP 상위 제품을 먼저 찾고 lot_status에서 LOT count, PROD_QTY, WF_QTY를 계산하는지 확인한다.

`hold_history`는 `LOT_ID` 필수 조회이므로 독립 단일턴 질문으로 검증하지 않는다. 아래 후속 질문 C처럼 먼저 LOT 목록을 얻은 뒤 같은 세션에서 이력을 조회한다.

## 5. 계획·실적·달성률

35. 7월 1일 제품별 INPUT 계획, 실제 INPUT 실적, 차이와 달성률을 알려줘.
    - 확인: target과 production을 제품 키로 결합하고 달성률을 계산하는지 확인한다.

36. 7월 1일 OUT 계획이 가장 큰 5개 제품을 보여줘.
    - 확인: target의 OUT 계획을 제품별로 집계하고 내림차순 정렬하는지 확인한다.

37. 7월 1일 INPUT 계획은 있지만 실제 INPUT 실적이 없는 제품을 알려줘.
    - 확인: 계획 데이터를 기준으로 left join하고 실적 누락 제품을 보존하는지 확인한다.

38. 7월 2일 제품별 계획을 알려줘.
    - 확인: 더미 데이터에 없는 날짜라면 다른 날짜 데이터로 대체하지 않고 결과 없음으로 답변하는지 확인한다.

## 6. 같은 세션에서 수행하는 후속 질문

아래 묶음은 각 묶음 안에서 같은 `session_id`를 사용한다.

### 후속 질문 A

1. 오늘 DA공정에서 생산량이 가장 많은 3개 제품을 알려줘.
2. WB공정에서는 어땠어?
3. 그중 재공도 가장 많은 제품은 뭐야?

확인: 2번은 오늘과 상위 3개 제품 분석 맥락을 유지하면서 공정만 WB로 변경하고, 3번은 직전 결과를 기준으로 재공을 추가 조회한다.

### 후속 질문 B

1. 7월 1일 제품별 INPUT 계획 대비 실제 INPUT 실적과 달성률을 알려줘.
2. 그중 달성률이 80% 미만인 제품만 보여줘.
3. 가장 부족한 제품부터 정렬해줘.

확인: 후속 질문에서 기준일과 제품 집계 조건을 유지하고 결과 필터·정렬만 변경한다.

### 후속 질문 C

1. 현재 HOLD 중인 LOT 목록을 알려줘.
2. 그 LOT들의 최근 HOLD 이력을 보여줘.
3. 이력이 가장 최근인 LOT 하나만 자세히 보여줘.

확인: 후속 단계가 첫 결과의 LOT_ID를 재사용하고 전체 unrelated LOT을 다시 조회하지 않는다.

### 후속 질문 D

1. 어제 BG공정의 생산량을 알려줘.
2. 이날 다른 공정은 어때?
3. 그럼 W/B공정만 세부 공정별로 보여줘.

확인: `이날`이 어제 날짜를 유지하고 오늘로 바뀌지 않으며, 마지막 질문에서 WB 그룹을 W/B1~W/B6으로 확장한다.

### 후속 질문 E

1. 현재 D/A1 공정에 배정된 장비를 알려줘.
2. 이 장비들의 Recipe와 UPH도 같이 보여줘.

확인: 두 번째 질문에서 첫 결과의 장비 식별자를 활용해 eqp_uph를 결합한다.

## 7. Metadata QA 작업자 질문

1. 현재 조회 가능한 데이터셋 목록을 보여줘.
2. 등록된 공정 그룹 도메인을 모두 알려줘.
3. BG 공정 그룹은 어떤 세부 공정을 포함해?
4. DA, WB, WBM 공정 그룹의 차이를 설명해줘.
5. 제품 집계는 어떤 컬럼들을 기준으로 해?
6. 일반 재공과 LOT 단위 재공 질문은 어떤 데이터셋을 사용해?
7. 장비 목록 질문과 LOT의 작업 장비 질문은 각각 어떤 데이터셋을 사용해?
8. eqp_uph 데이터의 기본 상세 표시 컬럼을 알려줘.
9. production_today를 조회할 때 필요한 파라미터와 실제 컬럼 mapping을 알려줘.
10. 공정 구간 조회에서 OPER_SEQ는 어떻게 사용해?

## 8. Router·Workflow 조합 질문

1. 오늘 DA공정 생산량을 알려주고, 이 분석에 사용한 데이터셋도 메타데이터에서 찾아줘.
   - 기대 순서: Data Analysis → Metadata QA

2. 오늘 DA공정 차수별 생산량을 조회한 뒤 막대그래프로 그려줘.
   - 기대 순서: Data Analysis → HTML Visualization

3. 오늘 WB공정 생산량과 현재 재공을 조회하고, 사용한 생산·재공 데이터 소스도 설명해줘.
   - 기대 순서: Data Analysis → Metadata QA

4. 오늘 BG공정 생산량을 조회하고 결과를 요약한 뒤, BG 공정 그룹 정의도 같이 알려줘.
   - 기대 순서: Data Analysis → Metadata QA → 최종 종합
