Data Catalog 선택 및 후속 질문 실제 검증 질문셋

목적

- 등록된 도메인과 Table Catalog만 근거로 데이터셋을 고르는지 확인한다.
- 단일 조회, 복합 조회, 현재 HOLD LOT의 후속 이력을 함께 확인한다.
- 질문자는 설정 용어를 사용하지 않고 평소처럼 질문한다.

단일 질문

1. [R01] 오늘 투입된 제품중 MCP NO가 L-267로 시작하는 제품의 INPUT 수량 알려줘
2. [R02] 어제 DA공정 차수별 생산량 알려줘
3. [R09] FCB 공정에서 SP 24G GDDR7 X32 226 FCBGA DDP 제품의 전일 생산량 알려줘
4. [R25] F315 L-116로 시작하는 제품 WB 공정 차수별 UPH 알려줘
5. [C10] PKG계획 데이터 7/6일자 보여줘
6. [C12] R0429 레시피로 할당된 장비 LIST를 알려줘
7. [C13] D/S1~D/A4 공정 HOLD 된 LOT ID 알려줘
8. [R29] 현재 HOLD 중인 LOT 목록과 LOT별 UNIT 수량, Wafer 수량, 현재·누적 TAT를 보여줘
9. [R30] 오늘 DA공정에서 생산량 상위 3개 제품과 각 제품에 할당된 장비 대수 및 LIST를 알려줘

후속 질문 시나리오

1. [R28 -> C01]
   - W/B공정 현재 HOLD LOT와 HOLD사유 알려줘
   - 위 LOT의 HOLD이력 알려줄래?
   - 확인: 첫 단계는 현재 HOLD LOT만 찾고, 두 번째 단계는 같은 LOT별 가장 최근 HOLD 시간·코드·상세 사유를 보여준다.

2. [현재 HOLD LOT -> C01]
   - W/B공정 현재 HOLD LOT와 각 LOT의 가장 최근 HOLD 코드 및 상세 사유를 알려줘
   - 확인: 현재 상태 조회 뒤 LOT별 최신 이력을 이어서 조회하며, 이력이 없는 LOT는 임의 사유로 채우지 않는다.

3. [제품 상위 3개 -> C02]
   - 오늘 DA공정 생산량 상위 3개 제품을 알려줘
   - 이 제품들에 현재 할당된 장비 대수와 장비 LIST를 제품별로 알려줘
   - 확인: 이전 제품 결과를 유지하고 장비 데이터를 결합한다.

검증 기준

- 등록되지 않은 데이터셋이나 컬럼은 추측해 실행하지 않고, 등록 정보가 부족하다고 안내한다.
- 날짜가 오늘이면 현재일 데이터, 어제면 이력 데이터를 사용한다.
- 레시피 번호는 완전 일치가 아니라 입력한 번호로 시작하는 값으로 찾는다.
- 후속 질문은 앞선 결과의 LOT 또는 제품을 이어서 사용하되, 새 질문의 조건을 무조건 상속하지 않는다.
