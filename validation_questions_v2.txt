Data Analysis Flow V2 검증 질문셋

분류 기준

- FAST: 최종 Resolver 기준 단일 external source, 지원 recipe, canonical filter/schema, 고정 또는 제한된 결과 계약을 모두 만족하는 질문이다.
- COMPLEX: 다중 source, join/비교, Function Case, 그룹 속성 비교처럼 자유 pandas 분석이 필요한 질문이다.
- BLOCKED는 정상 분류가 아니다. 필수 조회·schema·filter 계약 오류이므로 검증 실패로 처리한다.
- 아래 경로는 의도 LLM의 희망 경로가 아니라 `intent_plan.route_resolution.final_route`의 기대값이다.
- FAST 질문이라도 실제 metadata 계약이 불완전하면 Resolver가 COMPLEX로 안전 전환할 수 있다. 이 경우 `final_reason`을 확인해 metadata 또는 의도 계획 문제인지 판단한다.
- `eqp_down_list`, `eqp_utilization_today`, `eqp_history_today`는 이 질문셋 검증용 synthetic source다. 운영에서 5·22~25번을 사용하려면 같은 컬럼·시간 계약을 실제 Table Catalog에 별도로 등록해야 한다.

멀티턴 검증

멀티턴 공통 확인 항목

- 후속 질문 판정과 이전 상태 복원은 Fast/Complex 분기보다 먼저 수행된다.
- 따라서 후속 질문도 매 turn의 최종 실행 계약에 따라 FAST 또는 COMPLEX가 될 수 있다.
- 이전 source 하나를 재사용해 projection·filter·집계만 바꾸면 FAST가 가능하다.
- 이전 결과와 새 source를 결합하거나 두 source를 계속 비교하면 COMPLEX다.
- 이전 질문의 경로를 후속 질문이 그대로 상속한다고 가정하지 않는다.
